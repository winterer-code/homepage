# 법률사무소 올본 (OLBON LAW OFFICE) — 홈페이지

정적 사이트(HTML5 + CSS3 + Vanilla JS)입니다. 빌드 도구가 필요 없고, 폴더 전체를 웹호스팅에 올리면 바로 동작합니다.
브라우저에서 `index.html` 을 더블클릭해도 확인할 수 있습니다.

### 공통 헤더/푸터 수정 방법

`assets/js/layout.js` **한 파일만** 고치면 모든 페이지에 반영됩니다.
파일 상단 `SITE` 객체에 전화·주소·이메일·카카오 URL 등이 모여 있습니다.

```js
var SITE = {

  fax: "[팩스번호]",          // ← 교체
  bizNo: "[사업자등록번호]",   // ← 교체
  kakaoUrl: "#",              // ← 교체
  naverUrl: "#"               // ← 교체
};
```

## 3. 로고와 사진 — 적용 완료

### 로고

보내주신 로고 이미지에서 **네이비로 표시된 심볼만** 추출해 벡터(SVG)로 변환했습니다.
배경(아이보리)은 제거했고, 곡선을 다시 그려 확대해도 깨지지 않습니다.

색상은 요청하신 규칙대로 배경에 따라 자동 전환됩니다.

| 배경 | 로고 색 | 적용 위치 |
|---|---|---|
| 밝은 배경 | 네이비 `#0F2540` | 스크롤 후 헤더, 모든 서브 페이지 헤더 |
| 어두운 배경 | 샴페인 골드 `#D9C08F` | 히어로 위 투명 헤더, 푸터, 모바일 전체메뉴, 파비콘, 공유 썸네일 |

SVG 내부가 `fill="currentColor"` 라서 부모의 `color` 값만 바뀌면 색이 따라갑니다.
별도 파일이 필요하시면(명함·서류·이메일 서명 등) 아래 파일을 쓰시면 됩니다.

- `assets/images/logo-navy.svg` — 네이비 단색
- `assets/images/logo-champagne.svg` — 샴페인 골드 단색
- `assets/images/logo-symbol.svg` — 색상 미지정(currentColor)

웹사이트에 표시되는 로고는 `assets/js/layout.js` 의 `LOGO_SYMBOL_SVG` 값입니다.
나중에 로고를 새로 만드시면 이 문자열만 교체하세요.

## 4. 온라인 상담 폼 — 어디로 접수되나요?

### 지금 설정

상담 폼은 같은 폴더의 **`send.php`** 로 내용을 보내고, `send.php` 가
**`jhkim@olbonlaw.com`** 으로 메일을 발송합니다.
PHP를 지원하는 웹호스팅(카페24·가비아·닷홈 등)이면 파일만 올리면 바로 동작합니다.

```
방문자가 폼 작성 → send.php → jhkim@olbonlaw.com 으로 메일 도착
```

메일에는 성함·연락처·이메일·상담분야·상담내용·접수일시·접속IP가 정리되어 옵니다.
신청자가 이메일을 적었다면 **답장(Reply)** 을 누르면 바로 그 주소로 회신됩니다.

> **왜 외부 폼 서비스를 쓰지 않았나** — Formspree 같은 해외 서비스를 쓰면 상담 내용이
> 제3자 서버를 거칩니다. 변호사 비밀유지와 개인정보 국외이전 문제가 생길 수 있어,
> 내 호스팅 안에서 처리하고 바로 메일로 받는 방식을 기본으로 했습니다.

### 업로드 후 반드시 확인할 것

1. **`send.php` 를 `index.html` 과 같은 위치에 올렸는지**
2. **`send.php` 안의 `$FROM_EMAIL`** — 기본값은 `noreply@olbonlaw.com` 입니다.
   반드시 **내 도메인 주소**여야 합니다. 네이버·지메일 주소를 넣으면 스팸 처리되거나
   발송이 거부됩니다. 호스팅 관리자에서 해당 계정을 만들어 두세요.
3. **테스트 발송을 한 번 해보세요.** 실제로 폼을 작성해 제출한 뒤 메일함(스팸함 포함)을 확인합니다.

### 전송이 안 되면 어떻게 되나요?

내용이 사라지지 않도록 만들어 두었습니다.
전송에 실패하면 폼 아래에 안내가 뜨고 **[이메일로 보내기]** 버튼이 나타납니다.
누르면 메일 프로그램이 열리면서 **입력한 내용이 그대로 채워진 상태**로 준비됩니다.
전화 버튼도 함께 표시됩니다.

`olbon-preview.html`(미리보기 파일)이나 PC에서 `index.html` 을 직접 열었을 때는
서버가 없으므로 항상 이 안내가 뜹니다. **정상 동작입니다.**

### 다른 방식으로 바꾸고 싶다면

`assets/js/common.js` 상단의 한 줄만 고치면 됩니다.

```js
var CONSULT = {
  endpoint: "send.php",     // ← 여기만 변경
  ...
};
```

| 상황 | endpoint 값 |
|---|---|
| PHP 호스팅 (기본) | `"send.php"` |
| 자체 서버 API | `"/api/consult"` |
| 외부 폼 서비스 | `"https://formspree.io/f/XXXXXXX"` |
| 전송 없이 메일 작성만 | `""` (빈 문자열) |

호스팅이 PHP `mail()` 함수를 막아둔 경우에는 SMTP 방식으로 바꿔야 합니다.
[PHPMailer](https://github.com/PHPMailer/PHPMailer) 를 올리고 `send.php` 의 `mail()` 부분을
SMTP 발송 코드로 교체하시면 됩니다. 호스팅사 고객센터에 "PHP에서 메일 발송이 되는지,
SMTP 정보가 무엇인지" 문의하시면 바로 알려줍니다.

### 폼에 추가된 항목

회신을 위해 **이메일(선택)** 항목을 넣었습니다.
이에 맞춰 개인정보 수집·이용 동의문과 개인정보처리방침의 수집 항목에도
`(선택) 이메일` 을 함께 반영했습니다.

스팸 봇 차단용 숨김 필드(honeypot)도 넣었습니다. 사람 눈에는 보이지 않고,
봇이 채우면 서버에서 조용히 버립니다.

### 개인정보 관련 필수 조치

- **HTTPS 적용** — 상담 내용이 오가므로 필수입니다. 대부분 호스팅에서 무료 SSL을 제공합니다.
- **보유기간 관리** — 동의문에 "상담 종료 후 3개월 이내 파기"로 안내했습니다. 실제로 지켜주세요.
- `send.php` 의 `$SAVE_LOG` 는 기본 `false` 입니다. `true` 로 바꾸면 서버에 파일로 남는데,
  그 경우 해당 파일이 웹에서 열리지 않도록 반드시 접근 차단을 설정하세요.

## 5. 광고규정 준수 사항

대한변호사협회 변호사업무광고규정을 고려하여 작성했습니다.

- 전문분야 등록 전이므로 **“전문변호사”, “○○ 전문”** 표기를 사용하지 않았습니다.
  대신 “지식재산권 분야 실무 경험”, “IP 중심 업무” 등 사실 기반 표현만 사용했습니다.
- “승소율 100%”, “반드시 승소” 등 **결과 보장 표현을 사용하지 않았습니다.**
- 성공사례는 의뢰인 특정이 불가능하도록 익명·요약 처리했고,
  성공사례 페이지 하단과 푸터에 **“개별 사건의 결과는 사안에 따라 달라질 수 있습니다”** 고지를 삽입했습니다.
- 온라인 상담 폼에 **수집항목·목적·보유기간을 명시한 동의 항목**을 필수로 넣었습니다.

사례를 추가하실 때도 상호·지역·금액 등 특정 가능한 정보는 제외해 주세요.

## 6. 기술 사항

- **반응형**: 데스크톱 1440 / 태블릿 768 / 모바일 375 (1024px 이하 햄버거 + 전체화면 슬라이드 메뉴, 하단 고정 퀵바)

  - CDN이 차단된 환경에서도 첫 슬라이드와 모든 콘텐츠가 정상 노출되도록 폴백 처리했습니다.
- **SEO**: 페이지별 title / meta description / keywords / Open Graph, `LegalService`·`Attorney`·`FAQPage` JSON-LD, sitemap.xml, robots.txt
- **접근성**: 시맨틱 태그, 본문 바로가기 링크, 키보드 포커스 스타일, 탭 방향키 이동, `prefers-reduced-motion` 대응
  - 명도 대비 WCAG AA 확보를 위해 **밝은 배경 위 작은 골드 텍스트에는 `--gold-text: #8f7043`** 를 사용했습니다.
    (원본 `#B08D57` 은 흰 배경에서 3.09:1 로 AA 미달) 골드 버튼은 브랜드 컬러를 유지하고 글자를 네이비로 처리했습니다(5.00:1).
  - 로고용 샴페인 골드 `#D9C08F` 는 네이비 배경에서 8.75:1 로 여유 있게 통과합니다.

## 7. 휴대폰·태블릿에서 확인하는 방법

### 왜 휴대폰에서 압축을 풀어 열면 깨지나요?

**반응형 문제가 아닙니다.** 휴대폰이 로컬 HTML 파일을 여는 방식 때문입니다.

이 사이트는 `index.html` 이 같은 폴더의 `assets/css/…`, `assets/js/…`, `assets/images/…` 를
상대경로로 불러오는 일반적인 구조입니다. PC 브라우저는 이 경로를 그대로 따라가지만,
휴대폰은 그렇지 않습니다.

- **아이폰(iOS)** — 파일 앱에서 HTML을 누르면 사파리가 아니라 *미리보기(QuickLook)* 가 열립니다.
  이 미리보기는 보안상 **같은 폴더의 CSS·JS 파일을 불러오지 않습니다.**
  그래서 글자만 세로로 늘어선 상태로 보입니다.
- **안드로이드** — 파일 관리자가 HTML을 `content://` 라는 임시 주소로 브라우저에 넘깁니다.
  이 주소에는 "같은 폴더" 개념이 없어서 `assets/...` 를 찾지 못합니다.
- 압축을 풀지 않고 **ZIP 뷰어 안에서 바로 열었을 때**도 마찬가지입니다.
  그 경우 `index.html` 한 개만 임시로 꺼내지고 `assets` 폴더는 함께 나오지 않습니다.

즉 파일은 정상인데 휴대폰이 부속 파일을 같이 못 읽는 것입니다.

### 해결 방법 세 가지

**① `olbon-preview.html` 하나만 휴대폰으로 옮겨서 열기 (가장 간단)**

CSS·JS·이미지·13개 페이지를 **전부 이 파일 한 장에** 담아두었습니다.
부속 파일이 없으니 아이폰 미리보기에서도, 안드로이드 파일 관리자에서도, 인터넷 연결 없이도
그대로 열립니다. 메뉴·슬라이더·탭·상담폼·성공사례 필터까지 전부 동작합니다.
카카오톡으로 본인에게 보내서 휴대폰에서 열어보셔도 됩니다.

> 이 파일은 **확인용**입니다. 실제 서버에는 원본 폴더(`index.html` + `assets/`)를 올리세요.
> 내용을 수정하신 뒤 미리보기를 다시 만들려면 `python3 _build/make_onefile.py` 를 실행하세요.

**② 같은 와이파이에서 PC를 임시 서버로 띄우고 휴대폰으로 접속**

PC에서 이 폴더로 이동한 뒤 아래 명령을 실행합니다.

```bash
python3 -m http.server 8000
```

그다음 PC의 내부 IP(예: `192.168.0.5`)를 확인해 휴대폰 브라우저에서
`http://192.168.0.5:8000` 으로 접속하면 **실제 서비스와 완전히 동일한 상태**로 확인됩니다.

**③ 웹호스팅에 업로드**

카페24·가비아 등에 FTP로 폴더째 올리면 그때부터는 휴대폰에서도 아무 문제 없습니다.
**최종적으로는 이 방법이 정답**이며, 위 ①②는 업로드 전 확인용입니다.

### 참고 — 구형 기기 대응

혹시 오래된 아이폰(iOS 14 이하)이나 구형 안드로이드로 보실 수 있어
`inset`, `aspect-ratio` 같은 최신 CSS 속성에 폴백을 넣어 두었습니다.
아이폰 SE(320px)부터 태블릿(820px)까지 가로 스크롤이 생기지 않는 것도 확인했습니다.

### 전화 버튼이 눌리지 않던 이유

두 가지가 겹쳐 있었습니다.

1. **카카오톡·네이버 버튼** — 제가 URL을 몰라 `href="#"` 플레이스홀더로 두었습니다.
   눌러도 아무 일이 없는 게 정상이었습니다. 이제 실제 주소로 연결했습니다.
2. **전화 버튼** — 링크 자체는 정상이었지만, 휴대폰이 **파일 미리보기 상태**로 HTML을 열면
   보안상 `tel:` 같은 외부 앱 호출을 막습니다. 아이폰 파일 앱의 미리보기,
   안드로이드 파일 관리자의 `content://` 방식이 여기 해당합니다.
   **웹서버에 올린 뒤에는 정상 동작**합니다.

그래도 확인 중에 불편하지 않도록 **안내 기능**을 넣었습니다.
전화 버튼을 눌렀는데 0.9초 안에 통화 앱으로 넘어가지 않으면,
화면 아래에 전화번호와 **[번호 복사]** 버튼이 뜹니다. PC에서 눌렀을 때도 똑같이 동작합니다.

### 지도

지금은 **API 키가 필요 없는 구글 지도 iframe** 이 들어가 있어 바로 표시됩니다.
지도 아래에는 **네이버 지도에서 보기 / 카카오맵에서 보기 / 주소 복사** 버튼을 함께 두었습니다.
(지도가 로드되지 않는 환경에서는 자동으로 대체 화면과 버튼이 나타납니다.)

**네이버 지도로 바꾸고 싶으시다면** — 네이버는 공식 iframe 임베드를 제공하지 않습니다.
주신 것 같은 지도 링크는 `X-Frame-Options` 때문에 iframe 안에서 열리지 않습니다.
네이버 지도를 사이트에 심으려면 **네이버 지도 API** 를 써야 합니다.

<details>
<summary><b>방법 A — 카카오맵 '지도 퍼가기' (키 발급 불필요 · 3분 · 추천)</b></summary>

1. PC에서 [map.kakao.com](https://map.kakao.com) 접속
2. `서울 강남구 테헤란로 138` 검색 → 성홍타워 선택
3. 우측 상단 **지도 퍼가기** 클릭 → 크기 선택 → **소스 복사**
4. `location.html` 과 `index.html` 에서 `<iframe src="https://www.google.com/maps...">` 한 줄을
   복사한 스크립트로 통째로 바꾸기 (`<div class="map__embed">` 안쪽)

</details>

<details>
<summary><b>방법 B — 네이버 지도 API (네이버 계정 필요 · 무료)</b></summary>

1. [네이버 클라우드 플랫폼](https://www.ncloud.com) 가입 → 콘솔 → **Maps** → **Application 등록**
2. Web Dynamic Map 선택, **서비스 URL** 에 실제 도메인(`https://www.olbonlaw.com`) 등록
3. 발급받은 **Client ID** 를 아래 코드의 `발급받은ID` 자리에 넣고,
   `<div class="map__embed">` 안의 `<iframe>` 을 아래로 교체

```html
<div id="naverMap" style="width:100%;height:100%"></div>
<script src="https://oapi.map.naver.com/openapi/v3/maps.js?ncpClientId=발급받은ID"></script>
<script>
  // 좌표는 네이버 지도에서 해당 위치 우클릭 → '좌표 복사' 로 확인하세요
  var pos = new naver.maps.LatLng(37.5000, 127.0330);   // ← 실제 좌표로 교체
  var map = new naver.maps.Map('naverMap', { center: pos, zoom: 17 });
  new naver.maps.Marker({ position: pos, map: map, title: '법률사무소 올본' });
</script>
```

정확한 좌표는 네이버 지도에서 성홍타워 위치를 **우클릭 → 좌표 복사** 하시면 됩니다.
(임의로 지어내지 않으려고 위 코드에는 대략값을 넣고 주석으로 표시해 두었습니다.)

</details>

> 어느 방법을 쓰시든 지도 아래 **네이버 지도 / 카카오맵 버튼은 그대로 두는 것을 권합니다.**
> 휴대폰에서는 버튼을 누르면 앱이 바로 열려 길찾기까지 이어지기 때문에 실사용에 가장 편합니다.
